# راهنمای ورود ادمین به پنل مدیریت

## ۱. ساخت اولین حساب مدیر (فقط یک بار)

اگر هنوز مدیر اصلی (super) ساخته نشده، از ترمینال در پوشه پروژه:

```bash
python manage.py init-admin
```

- نام کاربری و رمز عبور را وارد می‌کنید (رمز باید **حداقل ۱۰ کاراکتر** باشد).
- اگر مدیر اصلی قبلاً ساخته شده باشد، دستور اجرا نمی‌شود و خطا می‌دهد (محافظت در برابر بازنویسی).

## ۲. ورود به پنل

1. مرورگر را باز کنید و به آدرس زیر بروید:

   ```
   http://127.0.0.1:5000/admin/login
   ```

   (در سرور انتشاری، به‌جای `127.0.0.1:5000` آدرس دامنه سایت را بگذارید.)

2. **نام کاربری** و **رمز عبور** را بنویسید و دکمه **«ورود»** را بزنید.

3. پس از ورود، وارد **داشبورد** پنل می‌شوید؛ از نوار کناری می‌توانید به
   اتاق‌ها، رزروها، مشتریان، نظرات، محتوا، رسانه، گزارش‌ها، زمان‌بندی،
   تنظیمات و گزارش فعالیت دسترسی داشته باشید.

## ۳. اگر رمز عبور را فراموش کردید

هیچ‌کس نمی‌تواند رمز شما را ببیند؛ فقط بازنشانی ممکن است:

```bash
python manage.py reset-password
```

- نام کاربری و رمز جدید (حداقل ۱۰ کاراکتر) را وارد کنید.
- این دستور در گزارش فعالیت مدیران ثبت می‌شود.

## ۴. ساخت مدیر دوم (اختیاری)

مدیر ثانویه فقط دسترسی‌هایی را دارد که به او بدهید:

```bash
python manage.py create-secondary --permissions "bookings.view,customers.view"
```

فهرست کلیدهای دسترسی در صفحه **مدیران** پنل (ویژه مدیر اصلی) نمایش داده می‌شود.
اگر برای مدیر ثانویه رمز موقت بگذارید، او پس از اولین ورود **مجبور است رمز را
از بخش پروفایل عوض کند** وگرنه به بقیه پنل دسترسی ندارد.

## ۵. نکات امنیتی ورود

- بعد از **۵ تلاش ناموفق در دقیقه** (به ازای هر IP یا هر نام کاربری)، ورود
  موقتاً قفل می‌شود و پیام «تلاش‌های ناموفق زیاد بود» نمایش داده می‌شود.
- نشست (session) بعد از ۱۲ ساعت بی‌کاری منقضی می‌شود؛ کافی است دوباره وارد شوید.
- حساب غیرفعال‌شده بلافاصله از پنل خارج می‌شود.
- همه ورودها، خروج‌ها و تغییر رمز در **گزارش فعالیت** ثبت می‌شوند.

## ۶. وضعیت سرویس‌ها

برای دیدن وضعیت کلی محیط اجرا کنید:

```bash
python manage.py doctor
```

درگاه پرداخت و پیامک تا زمانی که در `.env` فعال نشوند (`PAYMENT_ENABLED=0`،
`SMS_ENABLED=0`) به‌صورت خاموش و بدون ارسال واقعی کار می‌کنند — جزئیات
فعال‌سازی در `.env.example` آمده است.
